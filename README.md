# Степан — один день

Личный сайт: семь сцен от подъёма до сна, собранных в непрерывный цикл.
Полноэкранная Three.js-сцена, короткие подписи в пространстве и отдельные
панели для проектов, философских заметок и контакта.

## Сцены и персонаж

Подъём → город → ИТМО → проекты → безопасность / CTF → зал → сон → подъём.
Время в главах — часть рассказа, а не фактическое расписание.

Стилизованный персонаж смоделирован по предоставленной фотографии.
Четыре комплекта: домашнее худи с шортами и жёлтыми тапками; поло со
светлыми широкими брюками; лёгкая куртка с наушниками; спортивный комплект
с высоким воротом без рукавов. Походка, дыхание, моргание, работа за столом,
упражнения, пробуждение и сон анимируются программно.

## Запуск

Node.js 22.13+ и pnpm. Используйте существующий `pnpm-lock.yaml`.

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

В среде Sites используются штатные команды установки, сборки,
предпросмотра и публикации. `.openai/hosting.json` сохраняет идентичность
сайта. `.sites-runtime` содержит только локальные служебные данные.

## Основные файлы

- `app/components/DayExperience.tsx` — главы, тексты, панели и цикл дня.
- `app/world/scene.ts` — сцены, камера, свет и анимация.
- `app/world/avatar.ts` — геометрия персонажа и четыре комплекта одежды.
- `app/world/poster-frames.json` — привязки подписей для статичного режима.
- `public/scene-posters` — кадры той же геометрии для устройств без WebGL.
- `app/globals.css` — адаптивная вёрстка.

3D загружается отдельным модулем. Модели и шрифт хранятся локально.
На компьютере можно немного повернуть сцену перетаскиванием; мобильные
жесты оставлены для прокрутки. Уменьшенное движение учитывается, есть
ручная пауза. Открытая панель и пауза останавливают автоматический цикл.
При выключенном движении в конце доступна кнопка «Новый день».

Статичный режим включается при недоступности WebGL и сохраняет навигацию,
проекты, заметки, контакты и цикл дня. Постеры — рендеры этой же геометрии
с отдельным кадрированием для телефона; после изменения моделей их нужно
обновить. Исходная фотография на сайт не загружается.

## Контент

Проекты редактируются в массиве `projects`. Sync & MCP показан как ранняя
версия. «Истина как примитив» оформлена как рабочая заметка по тезису автора,
а не как опубликованная статья.

## Проверка

Проверены TypeScript, производственная сборка, открытие проектов и заметки,
навигация по главам и статичный режим в браузере. Геометрия и кадрирование
проверены отдельным OpenGL-рендером на экранах 1360×900 и 390×844.
Автоматическая проверка анимационного цикла покрывает сон, паузу,
блокировку открытой панелью и возвращение к подъёму.

Проверочный браузер не предоставляет WebGL-контекст. Финальная отрисовка
живой Three.js-сцены в браузере с GPU в этой среде не проверена.
